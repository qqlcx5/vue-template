# CxBacktop

## 设计意图
回到顶部按钮组件，页面滚动到一定距离后显示，点击平滑滚动回顶部。

## 功能边界
- 支持：自定义滚动容器、自定义显示阈值、自定义按钮内容、平滑滚动
- 不支持：滚动到指定锚点（仅回到顶部）

## 依赖
- Element Plus `el-backtop`

## 完整 API

### Props
| 参数 | 类型 | 默认值 | 必填 | 说明 |
|---|---|---|---|---|
| target | `string` | `''` | 否 | 滚动容器选择器 |
| visibilityHeight | `number` | `200` | 否 | 滚动到该距离后显示（px） |
| right | `number` | `40` | 否 | 距离右侧距离 |
| bottom | `number` | `40` | 否 | 距离底部距离 |

### Slots
| 插槽名 | 说明 |
|---|---|
| default | 自定义按钮内容 |
